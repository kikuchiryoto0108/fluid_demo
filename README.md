流体とシェーダー、その他技術の勉強を行っているプロジェクトです。
現在はローカル通信と、sph法を用い、スクリーンスペースにて描画をしている水が見れます。
AIに先生になってもらいながら、知識を吸収できればと考え、制作を行っています。

操作方法は、WASDで移動。マウス左クリックで水を飛ばせます。
テストプレイの際は、最初のウィンドウをYesで進めていただくとスムーズです。
